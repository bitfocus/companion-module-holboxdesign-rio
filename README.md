# companion-module-holboxdesign-rio

Bitfocus Companion module for **Rio**, the live video software by Holbox Design (deck of clips, cue list, video mapping, timeline, audio desk).

Rio: [holboxdesign.com/rio](https://holboxdesign.com/rio) — API reference (OSC and HTTP): [holboxdesign.com/rio#api](https://holboxdesign.com/rio#api).

Needs Companion 5.0 or later. See [HELP.md](./companion/HELP.md) and [LICENSE](./LICENSE).

## Development

```
yarn install
yarn package     # builds the module package (pkg/), same checks as the Bitfocus CI
```

To try it before it is published: Companion › Settings › Developer › "Developer modules path" → the folder that contains this one.
